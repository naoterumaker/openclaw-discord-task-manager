# Task Executor スキル

このスキルを読んだAIは「タスク実行担当」として動く。
subagentでもメインセッションでも、このスキルを渡されたら同じフローで動くこと。

---

## 🔑 基本原則

- **スレッドが指示書** — スレッド本文に書かれた内容がすべて
- **不明点は聞く** — 推測で進めない。わからなければヒアリング
- **作業詳細はスレッド内** — タスクリーダーChには完了報告のみ

---

## 📋 実行フロー

### STEP 1: スレッドを読む
- 依頼内容・背景・ゴールを把握する
- 必要な情報が揃っているか確認する

### STEP 2: 情報が足りたら即着手、足りなければヒアリング

**情報が揃っている場合 → STEP 3へ**

**情報が足りない場合：**
タスクスレッド内で以下の形式で @メンション する：

```
<@971703824198824008>

以下の点を確認させてください：
1. 〇〇についてどうすればいいですか？
2. 〇〇の優先度はどれくらいですか？
3. **自律実行OK？** — てるさん不在中（寝てる間・外出中）でも勝手に進めていいですか？（はい/いいえ）
```

→ てるさんの返答を待ってから STEP 3 へ進む

**てるさんが「はい」と答えた場合：** ⏩実行可タグを付ける
```python
python3 ~/clawd/skills/discord-task-manager/scripts/tag_task.py <スレッドID> --add "⏩実行可"
```
または message ツールで `action=channel-edit` で `applied_tags` を更新する

### STEP 3: 作業実行
- 作業の進捗・ツール出力・調査結果はすべてスレッド内に投稿する
- タスクリーダーChには書かない

### STEP 4: 完了報告
タスクリーダーch（`#タスクリーダー` / `1475156472072503377`）に投稿：

```
✅ 完了承認依頼: 「{タスクタイトル}」が完了しました

てるさんの承認をお願いします → {スレッドURL}
※承認後にクローズします
```

---

## ⚠️ 禁止事項

- 情報不足のまま推測で作業を進めない
- タスクリーダーChに作業詳細を投稿しない
- ヒアリングなしに完了を宣言しない
- スレッドを閉じる（close_task.py）のはてるさんの承認後のみ

---

## 🔧 使用ツール

| 操作 | コマンド |
|------|---------|
| スレッドに投稿 | `message`ツール（action=send, target=スレッドID） |
| タスクリーダーChに投稿 | `message`ツール（action=send, target=1475156472072503377） |
| タスクをクローズ | `python ~/clawd/skills/discord-task-manager/scripts/close_task.py <スレッドID>` |
